# Makes System

A versatile system for managing and purchasing makes in FiveM.

## Features

- Browse and purchase makes through an in-game menu
- Integration with ESX for economy and notifications

## Requirements

- FiveM server
- ESX framework
- MySQL database

## Installation

1. Download the script files
2. Place them in your FiveM server's resources folder
3. Add `start makesystem` to your server.cfg
4. Import the database.sql file into your MySQL database

## Usage

- Players can open the makes menu by typing `/makes` in chat or pressing the F7 key
- The menu displays available makes and their prices
- Players can purchase makes using in-game money

## Configuration

The script can be configured in the `config.lua` file. You can add or modify makes by editing the `Config.Makes` table.
